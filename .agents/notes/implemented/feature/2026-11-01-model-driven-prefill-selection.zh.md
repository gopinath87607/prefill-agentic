# Agent Note: 由模型选择预填充基线包含哪些文件

Status: implemented

[English](2026-11-01-model-driven-prefill-selection.md) | 中文

## 问题

确定性基线按最浅优先填满 token 预算，大型工作区因此把大部分预算花在顶层文件上，可能遗漏请求所需的模块。关键词匹配、扩展名启发式或路径邻近都无法判断陌生目录树中哪些文件能回答问题。用户要求由模型决定：宿主必须在注入任何内容之前询问模型哪些候选文件重要，并在压缩或工作目录变化迫使重新建立基线时再次询问。

## 决策

- 每次重新建立基线——第一个符合条件的步骤、工作目录变化、以及替换遮蔽快照后的第一步——都在准备基线之前运行一次辅助模型调用。增量更新从不调用模型，只追加已变化的已跟踪文件。
- 调用接收该步骤的请求文本与有界候选清单：按确定性最浅优先顺序排列的每个已扫描路径及其字节大小，受 `selectorInputTokens` 限制。请求文本最多占该预算的一半，因此超出预算的工作区只暴露较浅的路径。模型必须从列出的路径返回 `{"files":[{"path","reason"}]}`，并遵守 `selectorMaxFiles`、`selectorMaxOutputTokens` 与 `selectorTimeoutMs`。
- 路由为同时配置的 `selectorProvider`/`selectorModel` 对，否则为该步骤捕获的提供方与模型。宿主会对照候选清单校验每个返回路径，丢弃未知、重复、格式错误与超出上限的条目并计数；命名了条目却全部不可用的答案视为无效。
- 只读取被选中的路径，顺序即模型的优先顺序，每条提交的文件记录保留模型为该文件给出的简短理由。被选中但不适应预算的路径列入路径索引。未被选中的候选文件不会被读取，也不会进入快照。
- 任何失败都会在同一步回退到确定性最浅优先基线并记录原因：`no-candidates`、`no-request`、`llm-unavailable`、`no-route`、`timeout`、`stream-error` 或 `invalid-response`。`selection: 'deterministic'` 完全跳过该调用。
- 该调用仅写入日志。`prefill/selection-request` 在派发前记录确切的系统指令、消息、输出上限与清单计数；`prefill/selection` 记录结果、路由、耗时、用量、原始块与 `llmStreamCall: true`。重放从该事件重建辅助流，选择消息从不进入对话界面。
- 节省视图在注入估算值之旁扣除选择调用的提供方报告用量：`savedTokens = max(0, reusedTokens - injectedTokens - selectorTokens)`。`selectorCalls` 统计已派发调用，包括提供方未报告用量的那一次。
- 仪表盘的最近一次选择区块报告方式、路由、选中与丢弃计数、耗时、token 数，以及回退原因与诊断；文件行显示记录的理由。

## 考虑过的替代方案

**只用确定性最浅优先。** 它便宜、可复现且不需要路由，但按目录树位置而非相关性选择；当工作区深度超出预算时，最相关的文件无法被纳入。它保留为 `selection: 'deterministic'` 与回退路径。

**关键词与路径匹配。** 用户否决了它：固定词表无法表达哪些文件能回答任意请求，而错误匹配会静默注入误导性内容。

**在主模型中内联询问。** 对话内的选择步骤会让该决定对模型可见，并在每次基线前增加一个回合，重写预填充本应保持可缓存的前缀。辅助调用让对话保持仅追加，其确切输入与输出无需新增对话事件即可持久化。

**每个轮次都运行选择器。** 基线在重新建立之前是固定的，逐轮调用会为无法改变大部分快照的决定付出延迟与 token；增量更新已处理已变化与未跟踪文件。

**允许答案命名任意路径。** 无界提示会随工作区增长，并让虚构路径进入快照。有界清单也让对照封闭集合的校验成为可能。

**复用对话的推理流进行选择。** 把辅助输出混入可见回答会干扰答案，并破坏“每个模型请求一条事件”的约定，因此该调用以自己的请求用途记录独立事件。

**把选择 token 计为节省。** 排除它们会夸大节省；用户要求真实记账，因此成本被扣除并单独显示。

## 后果

- 重新建立基线现在要等待一次模型调用，最长 `selectorTimeoutMs`，并消耗至多 `selectorInputTokens` 输入与 `selectorMaxOutputTokens` 输出 token，会计费并从 `savedTokens` 中扣除。
- 清单限制了选择范围：大型工作区中的深层路径对选择器不可见。空答案会提交空基线，后续增量轮次随后会在 `deltaBudgetTokens` 范围内按最浅优先追加未跟踪文件。
- 相关性取决于对模型的信任：路径会对照候选清单校验，但顺序与理由不被评分。
- 两个新的必需、不可忽略会话事件意味着旧读取器会拒绝包含它们的日志；[持久化记录](../../../../docs/persistence-changes/2026-11-01-prefill-model-selection.zh.md)解释了该拒绝与可选的 `reason` 属性。
- 预填充文件记录与节省投影新增了选择状态，因此其 `stateVersion` 前进（文件记录 2、记账 4）；旧投影状态被丢弃并从日志重建。
